The Model

Central owns the why + what
  • Vision
  • Outcomes
  • Student Expectations
  • Director Expectations — green / yellow / red playbook
  • Approved Content Topics
  • Brand / Look
Campuses own the how
  • Time + Location
  • Experience
  • Contextualization
  • Activation
  • Relational Approach

Green / Yellow / Red Playbook

🟢 Green — Campus Ownership
  • Fun + relational elements
  • Student Task Force
  • Campus activations
  • Flow
  • Décor
  • Location + format
  • Budget within expectations
  • Serving expectations
🟡 Yellow — Alignment Needed
  • Student Expectations / Honor Code
  • HSL Values
  • Branding + graphics
  • Content outside approved catalog
  • Changes to semester plan / cadence
🔴 Red — Non-Negotiable
  • Meet consistently
  • Student Director ownership
  • Open to students meeting expectations
  • Clear communication channel
  • Move students toward Plant + Grow + Reach
